**I built an AI-powered DevOps Assistant in 10 days.**

It monitors infrastructure, detects anomalies, diagnoses root causes with Claude AI, and auto-fixes issues — all autonomously.

**How it works:**
6 AI agents running in a pipeline:
Monitor (30s) → Diagnose (60s) → Remediate (90s) → Learn (2min) → Predict (1hr) → Communicate (5min)

**Key features:**
- Real-time anomaly detection using z-score + moving average algorithms
- Claude API for intelligent root cause analysis with confidence scoring
- Auto-remediation with safety guardrails and human approval for high-risk actions
- Vector database (Qdrant) for learning from every incident
- Time-series forecasting to predict issues before they happen
- Slack notifications with interactive buttons + email alerts
- Natural language chat: "Why is the API slow?" → AI-powered answers

**Tech stack:**
Next.js | FastAPI | PostgreSQL | Redis | Prometheus | Claude API | Qdrant | Docker | Slack | GitHub Actions

**By the numbers:**
- 20,000+ lines of code
- 200+ files
- 88 automated tests
- 50+ API endpoints
- 6 AI agents
- 10 days of development

The system gets smarter over time — it learns from resolved incidents to diagnose future ones faster.
